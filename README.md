# 🍛 SPICE GARDEN

SPICE GARDEN is a responsive restaurant website for an authentic Indian restaurant. Customers can view the menu and place orders online. Admins can manage menu items and track orders through the admin dashboard.

## ✨ Features

**Customer Side**
- Responsive Homepage with Hero Banner and About Section
- Menu Display with Veg, Non-Veg, Biryani, and Starters categories  
- Contact Form for customer queries
- Mobile Friendly Design

**Admin Side**
- Secure Admin Login
- Add, Edit, Delete Menu Items
- View and Update Order Status
- Dashboard with Total Orders and Revenue

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
